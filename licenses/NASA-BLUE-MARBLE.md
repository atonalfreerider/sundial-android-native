# NASA Blue Marble Earth texture

`core/src/main/res/drawable-nodpi/earth_texture.png` is a color-adjusted derivative of NASA
Visible Earth's 2002 **The Blue Marble: Land Surface, Ocean Color and Sea Ice** global map.

- Canonical source: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.png
- Source collection: https://visibleearth.nasa.gov/collection/1484/blue-marble
- Local dimensions: 2048 × 1024
- Local SHA-256: `31612cf69021e77a4789e6a968186b95f58d6ce5131e115b20c4e4947ae3b81d`
- Credit: NASA Goddard Space Flight Center; image by Reto Stöckli; enhancements by Robert Simmon.

The local file preserves the source geography but has adjusted color values and PNG encoding, so
it is not byte-identical to the canonical download. NASA says its content is generally not subject
